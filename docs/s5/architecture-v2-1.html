Principes de conception
  • Les calculs (erreurs, conformité) sont déterministes et vérifiables dans le MVP.
  • L'agent relit, cite l'exigence (MC-xx / RD-xx / ETA-xx) et signale les étalons échus ; il n'approuve jamais.
  • L'approbation reste la signature d'une personne autorisée (§7.8.2.1 o — MC-14).
  • Clé API côté serveur (fonction controle-certificat) · prototype : données fictives uniquement.
  • Quota Groq gratuit 8 000 jetons/min : ≈ 5 300 jetons par contrôle → espacer les contrôles d'1 min.
  • Plan B S6 : « Mode démo » avec réponse enregistrée si l'API est indisponible.
